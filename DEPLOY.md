# Публикация на Timeweb Cloud

## Параметры приложения

Тип приложения: **Frontend → Next.js**  
Версия Node.js: **24**  
Команда сборки: **`npm run build`**  
Директория сборки: **`out`**  
SSR: **выключен**  
Автодеплой: **включить для ветки `main`**  
Регион: **Москва**  
Домен: **`staging.sanremomachines.ru`**

## Переменные окружения

```text
NEXT_PUBLIC_SITE_URL=https://staging.sanremomachines.ru
NEXT_PUBLIC_ALLOW_INDEXING=false
```

Для будущего боевого сайта разрешать индексацию можно только после проверки текстов и домена:

```text
NEXT_PUBLIC_ALLOW_INDEXING=true
```

## Ручная настройка после первого развёртывания

1. В Timeweb создать приложение из GitHub-репозитория `biotempbio/Sanremo_Site`, ветка `main`.
2. Внести параметры сборки и переменные окружения из разделов выше.
3. Добавить домен `staging.sanremomachines.ru` в приложение.
4. Скопировать DNS-запись, которую покажет Timeweb, в DNS-зону `sanremomachines.ru`.
5. Дождаться выпуска TLS-сертификата и проверить адрес по HTTPS.
6. Проверить, что `/robots.txt` содержит `Disallow: /`.

## Формы и внешние сервисы

- Заявки и запросы документов открывают почтовую программу посетителя с адресом `spokidov2017@gmail.com`.
- Серверной отправки форм, CRM, антиспама и хранения персональных данных на сайте пока нет.
- Изображения карточек каталога частично загружаются с `portal.holdingbio.ru` в браузере посетителя.
- Старый автономный прототип в `public/` содержит ссылки на CDN `unpkg.com`, но основные Next.js-страницы от него не зависят.
- Редиректы на стороне приложения не настроены. Если понадобятся старые URL или перенаправление между доменами, их нужно создать средствами Timeweb.

## Важное ограничение

Почтовая ссылка не гарантирует доставку заявки: отправка произойдёт только после того, как посетитель подтвердит письмо в своей почтовой программе. Для полноценной формы потребуется CRM или отдельный российский почтовый сервис; тогда отдельно понадобятся согласие на обработку персональных данных, защита от спама и обработка ошибок.
