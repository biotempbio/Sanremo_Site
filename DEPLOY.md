# Sanremo Russia — публикация

- Тип приложения: Frontend → Next.js
- Node.js: 24
- Команда сборки: `npm run build`
- Директория сборки: `out`
- SSR: выключен
- Автодеплой: включён для ветки `main`
- Репозиторий: `biotempbio/sanremo-russia-site`
- Staging: `https://staging.sanremomachines.ru`

Переменная окружения Timeweb:

`NEXT_PUBLIC_SITE_URL=https://staging.sanremomachines.ru`

Формы пока ведут в существующий контактный контур сайта. DNS при обычном обновлении не менять.
