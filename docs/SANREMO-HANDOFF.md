# Sanremo — передача контекста

Обновлено: 11 ноября 2026 года. Этот файл — стартовая точка для следующего
чата: сначала прочитать его, затем продолжать только в указанной ниже границе.

## 1. Цель и границы

- Рабочая среда нового сайта: `https://staging.sanremomachines.ru/`.
- `robots.txt` на staging закрыт от индексации; это намеренное состояние до
  приёмки и переключения.
- Боевой домен `https://sanremomachines.ru/` сейчас работает на Tilda. Не
  менять его, DNS и Tilda без отдельного согласования Сергея.
- Новый сайт должен быть справочником по профессиональным кофемашинам Sanremo
  в России: конфигурации, РРЦ, наличие, сервис, запчасти и дилеры доступны в
  HTML-страницах, а не только в PDF.

## 2. Инфраструктура

- Репозиторий: `biotempbio/Sanremo_Site`; рабочая ветка — `main`.
- Удалённые репозитории `origin` и `timeweb` получают одинаковые коммиты.
  Пуш в `timeweb/main` запускает автодеплой Timeweb App Platform для staging.
- Сайт — статический экспорт Next.js (`output: "export"`). На нём нет
  исполняемых серверных `redirects()` и middleware; HTTP 301 задаются в
  Timeweb Reverse proxy.
- В Timeweb ограничение — 10 правил. После удаления пяти ошибочных правил
  семейств действуют только четыре:

  | Источник | Цель | Код |
  | --- | --- | --- |
  | `/moments` | `/cases/` | 301 |
  | `/buy` | `/dealers/` | 301 |
  | `/products/f18sb/` | `/products/f18/f18-sb/` | 301 |
  | `/products/zoe-new/` | `/products/zoe/` | 301 |

## 3. Решения Сергея

- Кофемолки: раздел `/products/grinders/` и отдельная карточка
  `/products/x-one/`. Для X-One характеристики должны быть на странице, а
  цена и статус поставки — из данных BIO, если они есть.
- Napoli, Cube, Verona, Verona RS и Torino больше не поставляются. Они
  сохранены как архивные страницы на старых URL с сервисом, запчастями и
  ссылкой на актуальный выбор.
- `/page126418006.html` должен отдавать честную 404.
- F18 без уточнения SB называется `F18 MB` в карточках.
- Уценённые позиции (`У…` / `В…`) скрыты из витрины.
- Verona и Torino не продаются.
- Точное количество наличия показывать только от 3 единиц; единый источник
  цифр — `data/catalog.json`.

  staging после деплоя.
- Метрика в новом сайте загружается только на `sanremomachines.ru`, не на
  staging. Переменную `NEXT_PUBLIC_METRIKA_ID=114184245` нужно установить при
  сборке для основного домена перед переключением сайта с Tilda.
- 11 ноября создан счётчик Яндекс Метрики `114184245` в аккаунте
  `spokidov2017`: адрес `sanremomachines.ru`, Москва, Вебвизор и карта кликов.
  Вебмастер добавил `https://sanremomachines.ru`; метатег подтверждения
  `114d33d3fd4da962` включён в новый сайт. В проекте Sanremo на Tilda
  (`projectid=10550779`) ID счётчика сохранён в настройках аналитики, а
  метатег сохранён в HEAD. Сергей попросил сначала проверить неопубликованные
  правки. 11 ноября сверены
  предпросмотр Tilda и действующий сайт для всех 22 страниц: состав и тексты
  блоков совпадают. На главной также совпадают ссылки на изображения. Это не

  согласия Сергея Tilda опубликовала все 24 страницы; обычный адрес сайта
  отдаёт оба тега. Вебмастер подтвердил права аккаунта `spokidov2017` методом

## 7. Порядок работы

1. Claude проверяет каждый пакет на staging и присылает замечания.
2. Для каждого пакета: локальная сборка и проверки → коммит → push в `origin`
   и `timeweb` → ожидание автодеплоя → проверка staging.
3. После каждого пакета отправлять краткий отчёт с номером коммита, URL для
   проверки и известными ограничениями.
4. В конце каждого пакета обновлять этот файл.

`прочитай docs/SANREMO-HANDOFF.md и продолжай`.
