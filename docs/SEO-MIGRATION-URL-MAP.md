# Sanremo — карта миграции URL

Статус: черновик для согласования до настройки постоянных редиректов.

## Источник и правила

- Источник старых URL: `https://sanremomachines.ru/sitemap.xml`, снят 11 ноября 2026 года.
- Цели проверены на staging и отвечают `200`.
- После запуска постоянные редиректы настраиваются на Timeweb/Caddy. Для сохранения веса
  используется только `301`; цепочки и массовый перенос на главную запрещены.
- Адреса со статусом «решение требуется» не включать в конфигурацию до утверждения целевой
  страницы или решения отдать `410 Gone`.

## До запуска

1. Дополнить список URL из Яндекс Вебмастера, Google Search Console, Метрики и новостей `/tpost/`.
2. Отметить в таблице URL с кликами, позициями и внешними ссылками — они получают приоритетную
   ручную проверку.
3. Утвердить строки из блока «решение требуется».
4. Реализовать карту на уровне сервера и прогнать автоматическую проверку: каждый старый URL
   возвращает один `301`, а его конечная страница — `200`.
5. После смены доменной точки входа проверить те же ответы на `https://sanremomachines.ru`, а не
   только на staging.
