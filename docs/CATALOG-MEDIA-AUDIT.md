# Фотографии исполнений Sanremo — проверка 15.11.2026

Источник: полные карточки `GET /api/catalog/products/{code}` с ключом только в окружении Timeweb. На staging проверены все 59 позиций оборудования из выгрузки BIO: 57 кофемашин и 2 кофемолки. Сам ключ и дилерские данные в отчёт не попадают.

## Исправленная картина

| Результат | Исполнений |
|---|---:|
| Собственное фото из карточки шириной ≥800 px | 49 |
| Собственное фото меньше 800 px; крупное фото другого исполнения той же модели | 8 |
| Нет крупного фото этой модели в API; используется локальное официальное фото линейки X-One | 2 |
| Ошибка чтения полной карточки | 0 |

Прежний вывод «API выдаёт только маленькие превью» был неверным. Полная карточка возвращает `img` вида `/api/img/<GUID>` **без расширения** и `imageId`; отдельного массива `images/photos/gallery` среди 59 карточек нет. Скрипт прежнего аудита не распознавал адрес без `.jpg`. Прямое измерение файла Café Racer Racing, код 167326: **900×900 px**; маленький пример, GUID `ddc55a2d-76e6-11f1-b7a1-a87cb3c289fa`: **340×255 px**. Размер зависит от файла конкретной позиции.

Импорт теперь открывает полную карточку каждого исполнения, собирает `img` и любые появившиеся впоследствии поля галереи, измеряет исходные файлы через Sharp и выбирает самый крупный с шириной ≥800 px. Выбранный файл преобразуется в локальный WebP при сборке; посетитель сайта не обращается к порталу BIO. Для восьми позиций без крупного собственного файла выбран крупный файл той же модели, по возможности с тем же числом групп, с видимой подписью о возможном отличии цвета (и числа групп, если они различаются). Для X-One сохраняется локальное официальное фото линейки с честной подписью.

**Уточнённый запрос Александру Белякину:** нужны исходные фото шириной от 800 px именно для десяти перечисленных кодов, с привязкой к цвету и числу групп. Для остальных 49 кодов API уже отдаёт крупные изображения; расширять API для них не требуется. Если дополнительные изображения товара есть в данных портала, но отсутствуют в `GET /api/catalog/products/{code}`, полезно добавить их в это API как `images[]` с URL исходного файла. В интерфейсе портала у отдельных товаров видны миниатюры нескольких изображений, но экспортируемая полная карточка содержит только `img` и `imageId`.
