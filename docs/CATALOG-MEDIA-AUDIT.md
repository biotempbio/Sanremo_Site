# Фотографии исполнений Sanremo — проверка 15.11.2026

Источник: полные карточки `GET /api/catalog/products/{code}`. Ключ хранится только в окружении Timeweb. Проверены все 59 позиций оборудования в текущей выгрузке BIO (57 кофемашин и 2 кофемолки). Всего импорт получил 463 позиции, опубликовал 448 и скрыл 15. Остальные опубликованные позиции — запчасти; правило крупного фото исполнения к ним не применяется.

| Источник главного фото | Позиций |
|---|---:|
| Собственное фото из полной карточки, ширина не меньше 600 px | 50 |
| Фото того же цвета и отделки другой групповости | 5 |
| Официальное фото того же цвета и отделки | 0 |
| Нейтральная заглушка: крупного фото подходящего цвета нет | 4 |
| Ошибка чтения карточки | 0 |

Импорт проверяет все изображения, которые возвращает полная карточка, измеряет файлы и сохраняет выбранные фотографии в локальном WebP. Для текущих 59 карточек API возвращает `img` и `imageId`, но не отдельный массив `images/photos/gallery`; скрипт готов обработать такой массив, если он появится. Маленькие превью не растягиваются в главный визуал. Посетитель не обращается к порталу BIO при открытии страницы.

Для этих четырёх кодов нужен исходник не меньше 600 px по ширине именно выбранного цвета/отделки. Дополнительные изображения в интерфейсе портала полезно включить в `GET /api/catalog/products/{code}`, если они существуют: сейчас полный ответ API отдаёт только `img` и `imageId`. Прежний вывод «API выдаёт только маленькие превью» был ошибочным: например, Café Racer Racing 167326 приходит в размере 900×900 px.

Структурированное поле групп в API для Café Racer Custom Renegade 188441 и F18 SB 188422 расходится с названием товара; группа на сайте приведена к явно указанной в названии. Выбор группы и кнопки вариантов проверены отдельно: 2-групповое и 3-групповое исполнения больше не смешиваются, одинаковые подписи кнопок не дублируются, артикул показан только после выбора.
