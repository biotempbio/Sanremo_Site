## Оригиналы через BIO API

Документация `/product` и `/products` содержит поле `img` с URL превью, но не содержит поле оригинала или параметр размера. Проверка одного D8: исходный URL и варианты `?width=1440`, `?w=1440`, `?size=original`, `?original=1` вернули одинаковые 278×185 px PNG (39 788 байт). У Café Racer на staging выбранное превью — 340 px. Этого недостаточно для основного изображения.

Запрос для Александра Белякина: добавить в экспорт `GET /api/catalog/export?brand=Sanremo` поле `imageOriginalUrl` либо `images[].originalUrl` для каждого SKU. URL должен отдавать исходный файл от 1440 px по ширине через HTTPS по `BIO_CATALOG_API_KEY` при сборке, без браузерной сессии. Нужны также `width`, `height`, MIME-тип и привязка изображения к конкретным группе и цвету. Тогда оригиналы можно скачивать во время сборки в `public/photo/catalog/<code>` и генерировать srcset 480/960/1440. До появления этих данных нельзя выдавать фото одной версии за другую.
