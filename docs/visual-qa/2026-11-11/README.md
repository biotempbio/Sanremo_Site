## Критерии

- Шрифты совпадают с главной и карточкой: локальные Oswald для заголовков,
  Roboto для текста; кириллица отображается. H1 статей 32 px на 390,
  36 px на 1280 и 40 px на 1920.
- Колонка статьи ограничена 720 px и центрирована; таблица сравнения занимает
  ширину контейнера. Перед H2 — 64 px на desktop и 52 px на мобильном,
  между абзацами — 16 px.
- На всех 15 снимках ширина документа совпадает с шириной viewport:
  горизонтального переполнения страницы нет. Таблица прокручивается внутри
  собственной обёртки, с подсказкой на мобильном.
- Семь строк сравнения без перечислений через точку с запятой. Проверены
  раскрытие FAQ, переход к группе «Сервис» и ссылки на карточки.
