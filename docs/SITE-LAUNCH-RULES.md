# Правила переключения сайта между платформами

## DNS и старая платформа

Домен в старой платформе отвязывать только через **TTL + 1 час** после смены DNS-записей. До этого часть посетителей может обращаться к старому IP из кэша резолвера. Старая платформа должна продолжать показывать рабочий сайт, а не заглушку.

Перед отвязкой проверить DNS через `dns.google` и ещё 2–3 независимых публичных резолвера: `@` и `www` должны возвращать новый адрес. Затем проверить новый сайт, SSL, основные страницы и доставку заявок. Сохранить проект старой платформы как точку отката.

## Инцидент Sanremo, 12 ноября 2026

После перевода `A @` и `A www` на Timeweb домен слишком рано отвязали от Tilda. Резолверы, сохранявшие старый IP `176.57.65.159` при TTL 6 часов, показывали заглушку Tilda `Domain has been assigned`.

В тот же день поле домена проекта Tilda `10550779` восстановлено как `sanremomachines.ru`. DNS не меняли, страницы Tilda не перепубликовывали. Через прежний маршрут проверено: `sanremomachines.ru` снова показывает старую главную Tilda; `www` ведёт на неё же. Следующая отвязка допустима только после проверки истечения TTL и независимых резолверов.
