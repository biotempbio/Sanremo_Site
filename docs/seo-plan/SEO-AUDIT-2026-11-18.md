## Что удерживает выпуск

1. **Ключ каталога BIO:** Timeweb API 200, но запрос синхронизации с уже настроенным `BIO_CATALOG_API_KEY` получил HTTP 401. Синхронизация остановилась с ошибкой; данные не заменялись. В репозитории `bio-catalog.snapshot.json` содержит 0 записей изначально; локальная сборка использует существующий `catalog.json` как предусмотренный резерв. Проверка с текущими 448/иным числом опубликованных позиций и актуальными фотографиями ещё не пройдена. Перед production нужен рабочий ключ и успешная повторная синхронизация.
2. **Управляемый Caddy Timeweb:** файлы `ops/web/*` проверены локально, но не подключены к frontend App Platform. Публичная схема обновления приложения не содержит `reverse_proxy`, а поддержка заголовков по пути не подтверждена. Подробности — `ops/web/README.md`. Не выполнены изменения production, создание приложений, смена тарифов или DNS.
3. Требуется ревью готового пакета до слияния в `main`, как указано в брифе. После публикации все HTTP-проверки следует повторить на https://sanremomachines.ru/ с актуальными хэшами чанков.
