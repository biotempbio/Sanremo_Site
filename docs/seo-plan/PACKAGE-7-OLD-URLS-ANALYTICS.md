## 2. Выкатить правку целей Метрики

В рабочей копии уже изменён `app/components/AnalyticsEvents.tsx`: из условия в начале `useEffect` убрана проверка `!window.ym`. Причина: скрипт Метрики грузится `afterInteractive` и появляется позже, чем срабатывает этот эффект, поэтому клики по телефону, почте и дилерам при первой загрузке страницы не уходили в цели. Вызов `window.ym?.(…)` внутри `goal()` уже безопасен.

Проверь правку, закоммить только этот файл и выкати. Проверка на боевом домене: при первой загрузке страницы клик по `tel:` вызывает `ym(114184245, 'reachGoal', 'phone_click')` (подменить `ym` шпионом в консоли или посмотреть запрос `mc.yandex.ru/watch/...` с целью).
