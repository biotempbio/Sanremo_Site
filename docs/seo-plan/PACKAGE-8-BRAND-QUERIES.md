# Пакет 8 — бренд-запросы: линейки, конфигурации, каталог (план «Sanremo в поиске», этап 2)

Постановщик и приёмка: Claude. Начинать после выкатки пакета 7.

## Зачем

По запросам «sanremo d8» (419 в месяц), «sanremo zoe» (311), «кофемашина sanremo» (1 032), «кофемашина сан ремо» (402), «sanremo cafe racer» (187+133), «sanremo d8 pro» (108) в топ-10 Яндекса по Москве стоят только дилеры: Tintins, Chefpoint, Refro, Р-Комплект, Ligabarshop. Официального сайта там нет. У дилеров выигрывают страницы конкретных конфигураций: в заголовке слово «кофемашина», модель, число групп, цена и наличие. Задача — чтобы официальный сайт стоял первым по своим бренд-запросам, как lamarzocco.su по «la marzocco linea».

Правило текстов: не делать акцент на BIO и не писать «РРЦ» — просто «цена». Ничего не придумывать: цены, наличие, характеристики — только из `data/catalog.json` и проверенных данных.

## 1. Страницы линеек (`/products/<family>/`)

- `title`: «Кофемашина Sanremo D8 — цены и наличие у официального дистрибьютора» (по образцу для каждой линейки; до ~70 знаков).
- `h1`: «Кофемашина Sanremo D8».
- `description`: цена «от …» (минимум по активным конфигурациям, считается из данных), варианты по числу групп, наличие на складе.
- В первом абзаце один раз естественно: «Sanremo (Сан Ремо)». Русское написание ищут 400 раз в месяц.
- Таблица конфигураций с текстовыми данными: артикул, группы, бойлеры, мощность, напряжение, цена, наличие. Без картинок вместо цифр.
- Вопросы и ответы: не меньше 6, с цифрами — цена, срок под заказ (6–8 недель из Италии), гарантия 12 месяцев, монтаж и запуск через дилеров и сервисных партнёров, лизинг (есть, страница появится в этапе 3), на какой поток чашек рассчитана линейка.
- Блок кейсов с этой линейкой (из `data/cases.json`), если они есть.
- Разметка: `Product` с `AggregateOffer` (lowPrice, highPrice, `priceCurrency: RUB`, offerCount), `brand: Sanremo`; `BreadcrumbList`; `FAQPage`.

## 2. Страницы конфигураций (`/products/<family>/<model>/`)

- `title`: «Sanremo D8 PRO, 2 группы — цена, характеристики, наличие».
- `h1`: «Кофемашина Sanremo D8 PRO, 2 группы».
- Артикул(ы) текстом, полная таблица характеристик, цена, наличие (точное число от 3 шт., как решено ранее), документы ссылками.
- Разметка: `Product` + `Offer` (price, `priceCurrency`, availability, `sku`/`mpn`, url), `BreadcrumbList`.
- Перелинковка: с главной и из каталога есть путь к каждой конфигурации не длиннее двух кликов.

## 3. Каталог `/products/`

- `title`: «Кофемашины Sanremo (Сан Ремо) — официальный дистрибьютор в России, цены и наличие».
- Вводный текст 2–3 абзаца с фактами: 7 линеек, диапазон цен «от … до …» из данных, гарантия, срок поставки, дилеры по стране.
- Фильтры по числу групп и типу бойлера — если их нет, добавить.
- `ItemList` уже есть — проверить, что в нём все линейки и кофемолки.

## 4. Товарный фид для Яндекса

- Сгенерировать `https://sanremomachines.ru/feed/yandex.yml` (формат YML): все активные конфигурации и X-One — `id`, `url`, `price`, `currencyId RUB`, `picture`, `vendor Sanremo`, `model`, `available`, `description`, категории по линейкам.
- Пересобирается вместе с ночным обновлением остатков.
- Подключение фида в Вебмастере («Товары и цены») делаю я.
